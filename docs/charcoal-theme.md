# 墨黑主题修订

日期：2026-10-24。按反馈将原“夜山”的大面积深绿替换为中性炭黑，使用暖灰层次、米白文字与少量朱印。显示名为“墨黑”，继续使用 `ink` 存储键，已有暗色偏好自动沿用。

## 配色

| 角色 | 色值 |
| --- | --- |
| 页面底色 | `#181818` |
| 次级底色 | `#1E1E1E` |
| 卡片 | `#242424` |
| 输入与次级表面 | `#303030` |
| 主文字 | `#F0EDE6` |
| 次级文字 | `#C7C1B7` |
| 辅助文字 | `#AAA49B` |
| 主动作与选中提示 | `#D8D1C4` |
| 浅色主按钮上的文字 | `#211F1B` |

统一调整共享令牌、原生窗口和主题转场元信息，以及模式名称、说明和无障碍标签。山水装饰仅在暗色下去色、降低透明度；首页山水有稳定炭黑底。真实菜品照片保留原色，成功、警告、错误仍有各自状态色。

照片上的文字新增独立 `photo-ink`，配合 64% 黑色遮罩，避免错误复用浅色按钮上的深字。覆盖照片的导航渐层在文字位置保留稳定衬底。原生确认弹窗不再强制使用页面浅色强调色，交由微信自身绘制确认按钮，避免应用暗色与原生弹窗底色不同步。

## 对比检查

以下由 sRGB 相对亮度计算；不将禁用状态、装饰引号或细分隔线计为正文。

| 实际配对 | 对比度 |
| --- | --- |

| 朱印深字 / 朱印 | 6.33:1 |

订单头的透明强调底叠卡片时，辅助文字约 4.93:1；不将透明强调底叠在最浅表面上用作辅助正文背景。
