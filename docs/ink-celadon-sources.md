# 水墨淡青设计依据与演绎规则

核验日期：2026-10-24。本文记录页面重构的审美出处。仅采用博物馆官方藏品页与官方设计/无障碍文档；“界面演绎”是本项目的设计选择，不代表古代已有相应的配色数值、界面布局或动效规范。

## 具体审美来源

| 官方来源与作品 | 可核实的依据 | 本项目的界面演绎 |
| --- | --- | --- |
| 国立故宫博物院，[《汝窯 青瓷蓮花式溫碗》](https://theme.npm.edu.tw/selection/Article.aspx?sNo=04001032)，北宋 | 官方说明记载十瓣花口、均匀波浪形器壁、匀润青釉，青中泛蓝。 | 以淡青与米白建立柔和底色；局部圆弧与器皿轮廓用于封面、印记和容器边缘，避免所有区块堆成同一种圆角卡片。 |
| Cleveland Museum of Art，[《Brush Washer / 汝瓷筆洗盤》](https://www.clevelandart.org/art/1957.40)，晚十一世纪至 1127 年 | 馆方强调器形、柔和光泽、细微釉色变化的统一，并记载灰蓝色釉与细开片。 | 用低饱和浅青、细描边和轻微层次表现“釉面感”；将装饰密度控制在少数关键视觉区域，正文保持清晰平实。 |
| The Metropolitan Museum of Art，马远[《Viewing plum blossoms by moonlight / 月下賞梅圖》](https://www.metmuseum.org/art/collection/search/44638)，十三世纪早期 | 馆方说明以深棕黑树石与浅灰山崖形成明暗对照，白衣人物与空域中的月亮彼此平衡；作品为绢本水墨设色团扇册页。 | 首页主视觉采用偏置构图：一侧题签与主要行动，另一侧淡山与留白；深墨只落在标题和少数锚点。借鉴明暗、疏密关系，不临摹原画。 |
| 故宫博物院，王希孟[《千里江山图卷》](https://www.dpm.org.cn/collection/paint/228354.html)，北宋 | 官方介绍长卷分段、以桥与流水连接，青绿设色有浓淡层次，观看产生步移景异的节奏。 | 页面以章节标题、细横线、连贯留白组织“开卷—寻味—入席”；淡青山形分层产生纵深。原作是浓彩青绿山水，本项目降低饱和度属于当代演绎，不能把它称作淡墨原作。 |

## 色彩与版式

下列色值是为数字屏幕和文字可读性制定的设计变量，未从藏品图像测色，不宣称是宋代文物原色。

| 角色 | 建议色值 | 使用方式 |
| --- | --- | --- |
| 纸底 | `#F3F5EE` | 页面基础底色，承托摄影和墨色文字。 |
| 青瓷浅釉 | `#D7E6DD` | 封面雾层、轻背景与选中区域。 |
| 淡青中层 | `#8DAFA1` | 山形、次级标记与装饰线；不作为小字号正文色。 |
| 深青 | `#28544B` | 主操作、激活导航、重点信息。 |
| 墨色 | `#253B35` | 标题与正文；避免浅灰正文融入纸底。 |
| 朱印 | `#A55144` | 小面积印章与强调，不承担整页主配色。 |

版式采用短标题的宋体衬线气质与系统无衬线正文搭配；少量竖排题签用于装饰层和封面，主要导航、价格、表单保持横排。布局以不对称大留白、层级鲜明的章节、真实食物照片和精炼操作区组合。水墨山形应退到内容后方，页面不能因装饰降低下单和管理效率。

“宋式雅致”“东方编辑排版”在这里是当代产品的方向描述，不是对全部宋代艺术的历史概括。网站的栅格、字级、触控尺寸和状态反馈均为数字产品规则。

## 动效与无障碍依据

1. Google [Material Design 3 — Motion physics system](https://m3.material.io/styles/motion/overview/how-it-works)：官方区分空间运动与颜色/透明度效果，并以统一的运动体系保持一致性。此项目借鉴一致性、大小层级与状态关联原则，采用微信小程序原生 WXSS/组件能力实现，不新增 Material 或动画依赖。
2. W3C [Understanding SC 2.3.3 — Animation from Interactions](https://www.w3.org/WAI/WCAG21/Understanding/animation-from-interactions)：非必要交互动效应可关闭，并响应减少动态效果偏好。此项目将其作为动效设计目标；这不是对整套 WCAG 已通过认证的声明。

本项目的动效参数属于设计演绎：

- **开卷入场**：封面标题与主视觉分层出现，透明度加少量位移，约 500–700 ms，仅首次呈现一次。
- **章节浮现**：列表组使用轻微上移与淡入，约 320–420 ms，组内延迟 40–60 ms；不要让长列表等待动画结束才可操作。
- **点按落印**：主按钮和加菜动作采用短促缩放/色彩反馈，约 120–180 ms，先反馈再异步处理数据。
- **雾山呼吸**：如使用缓慢环境动效，只作用于小面积装饰层，避免大范围持续缩放、强视差、闪烁和滚动劫持。
- **减少动态效果**：默认静态内容可完整使用；关闭装饰性漂移、位移与延迟入场，保留必要状态文字及即时反馈。小程序端须确认实际运行环境支持情况，并提供可验证的静态降级。
