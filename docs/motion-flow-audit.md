# 页面流转与动效复查

日期：2026-10-24。范围为全部 12 页、公共导航、底部导航、主题切换，以及保存、删除、点菜与订单反馈。

## 已修复

| 场景 | 问题与处理 |
| --- | --- |
| 快速点击页面入口、返回和点菜单 | 导航统一防重；目标页显示且原生回调完成后释放锁。失败恢复可点击状态，超时只解锁，不重复导航。 |
| 底部标签切换失败 | 选中态按实际页面同步，避免先移动指示器后跳转失败。取消底栏每次挂载时的入场动画。 |
| 返回已有页面 | 不再重播标题、图文和列表的整套开场。整页容器保持不透明，降低夜山主题露出浅色底的风险。 |
| 页面隐藏或卸载 | 停止轮播自动播放，暂停加载动画，清理飞入、回弹、计数、移除、订单高亮和延迟跳转任务；拦截过期的跳转回调。 |
| 保存、删除完成后返回 | 成功状态单独记录，防止反馈等待期间重复创建；页面仍显示时才返回，隐藏后留待再次显示处理。 |
| 移除最后一道菜后立即提交 | 移除过渡期间禁止提交，并在调用前校验实际点菜单，避免提交空单。 |
| 下单请求未结束时离页 | 成功后仅移除本次提交的菜品，保留后来新加的菜品；避免后台成功回调突然切走当前页面。 |
| 入场尚未结束就发现权限不足 | 等当前导航释放后执行一次回退；隐藏、卸载或新一轮显示会取消过期回退，不轮询。 |
| 减少动效 | 计数立即到目标，主题直接提交终态，保存和落单反馈不等待动画；订单高亮保留静态提示。 |
