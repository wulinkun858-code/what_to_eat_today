# 坤坤菜单 · 设计系统 v2（主题与动效重构）

> 依据：Apple HIG（Clarity / Deference / Depth）+ `ui-motion-craft` 的 10 种交互模式与动效令牌
> 预览：`theme-preview.html`（工作区根目录，可点击色块看圆形扩散换肤）

---

## 一、设计哲学（先定原则，再写样式）

1. **因果优先**
   每个动效必须回答三件事：从哪来、改变了谁、去哪了。换主题从指尖铺开，是因为用户的手指在那里；
   点「想吃」的粒子飞向点菜单，是在交代东西去了哪。做不到这三点的动画一律删掉。

2. **排版先于装饰**
   层级靠字号、字重、留白和发丝线建立，而不是靠阴影、毛玻璃和卡片套卡片。
   v1 用「卡片 + 阴影 + 圆角」表达所有层级，结果每一屏都在喊；v2 把卡片压到只剩一层表面，
   用 60rpx 的刊头、20rpx 的字距标签、1rpx 的分隔线来分层。

3. **一套材质**
   全局只有两种表面：`--surface`（卡片/输入/浮层）与 `--bg`（页面）。
   所有卡片同一圆角（32rpx）、同一发丝线（`--line`）、同一阴影（`--shadow-sm`）。
   不在同一屏混用 12/16/24/28rpx 四种圆角——那是「随手写」的味道。

4. **颜色克制**
   中性底 + 单一强调色。语义色（成功/信息/警告/危险）只在状态里出现，不参与装饰。
   两套主题共用同一套结构变量，换主题只换值，不换布局。

5. **动效预算**
   100 / 200 / 300 / 460 / 600ms 五档，按「微反馈 → 元素移动 → 区域变化 → 整页转场」分配。
   任何单个动画不超过 700ms；过冲不超过 8%。

6. **性能就是设计**
   卡顿不是「动画太快」，是画错了属性。v2 的硬约束：
   - 只动 `transform` / `opacity`，不碰 `width/height/top/left`
   - 禁止 `transition: all`（会把 `box-shadow`、`filter` 一起带上）
   - 禁止给 `box-shadow` 加过渡（大范围阴影逐帧重绘，低端机必掉帧）
   - **全项目移除 `backdrop-filter`**：它要在滚动时逐帧采样背景，是 v1 卡顿的主因之一
   - 骨架屏用透明度呼吸，不用渐变位移（少一个数量级的绘制）

## 二、令牌

### 颜色（两套主题，变量名完全一致）

| 变量 | 用途 | 暖沙 sand | 黑金 gold |
|---|---|---|---|
| `--bg` | 页面底 | #F7F3EC | #0A0A0B |
| `--bg-2` | 页面次底 | #F1EBE1 | #121110 |
| `--surface` | 卡片/浮层 | #FFFFFF | #151311 |
| `--surface-2` | 次级底/标签 | #F3EDE4 | #201D18 |
| `--ink` | 主文字 | #1C1917 | #F4ECDD |
| `--ink-2` | 次级文字 | #6B635A | #B6A88E |
| `--ink-3` | 辅助/占位 | #A39A8E | #7E725F |
| `--line` | 发丝线 | rgba(28,25,23,.08) | rgba(212,175,55,.16) |
| `--accent` | 强调 | #C05621 | #D4AF37 |
| `--accent-ink` | 强调上的文字 | #FFFFFF | #17130A |

另有 `--accent-soft` `--ok` `--info` `--warn` `--danger` `--danger-soft` `--shadow-sm` `--shadow-md`。

> 黑金不是「纯黑 + 亮黄」：底色 #0A0A0B 近黑但留一点暖，分隔线是 16% 透明的金，
> 强调金 #D4AF37 上压深色字（`--accent-ink`），对比度约 8:1。

> **关键工程点**：微信自定义组件默认 `styleIsolation: isolated`，`app.wxss` 里的 class 规则
> **不会进入组件内部**。所以主题变量抽到 `styles/theme.wxss`，tabBar 等组件各自 `@import` 一次，
> 否则组件内 `var(--surface)` 解析失败 → 背景透明、文字继承黑色。

### 排版

| 类 | 字号/行高 | 用途 |
|---|---|---|
| `.display` | 60rpx / 1.14 / 700 / -1rpx | 页面刊头（今天想吃点什么） |
| `.h1` | 44rpx / 1.25 / 700 | 区块主标题 |
| `.h2` | 32rpx / 1.35 / 600 | 列表标题 |
| `.body` | 28rpx / 1.7 | 正文 |
| `.caption` | 22rpx / 1.5 | 辅助信息 |
| `.eyebrow` | 20rpx / 字距 3rpx | 分区标签（全大写感） |

数字统一 `.num`（`tabular-nums`），避免滚动计数时宽度抖动。

### 动效

| 令牌 | 值 | 用途 |
|---|---|---|
| instant | 100ms | 按压、颜色微变 |
| micro | 200ms | 按钮、开关 |
| move | 300ms | 让位、展开 |
| area | 460ms | 圆形扩散、区域变化 |
| `--ease-out-quint` | cubic-bezier(.22,1,.36,1) | 扩散、入场（快进长尾） |
| `--ease-spring` | cubic-bezier(.34,1.56,.64,1) | 小元素回弹（≤8% 过冲） |
| `--ease-spring-mid` | cubic-bezier(.34,1.4,.64,1) | 中位移弹性 |

## 三、主题切换：对角渐变扫过（左上 → 右下）

### 方案
一块 **3 倍屏大小**的渐变层，`linear-gradient(135deg, 新底色 0%, 新底色 32%, 次底色 48%, 强调色·30% 56%, 透明 64%)`。
起始时把「透明的那一角」对准屏幕（`translate(-66.667%, -66.667%)`），然后沿对角线平移到 `translate(0,0)`，
渐变前沿从左上角斜扫到右下角，中段带一条柔和的金/橙色彩过渡。

```
0ms     渐变层落位，透明角对准屏幕
24ms    开始沿对角线平移
1024ms  扫满整屏（transition 1000ms，cubic-bezier(.4,0,.2,1)）
1030ms  换肤（画面被完全盖住，重绘看不见）
1050ms  遮罩淡出 200ms
1260ms  复位、解锁
```

- 用户要求**用 1 秒去看这个渐变**：所以曲线用标准 S 曲线（`.4,0,.2,1`），
  中段接近匀速；如果沿用 `ease-out-quint`，前 250ms 就走掉 70%，剩下 750ms 几乎不动，像卡住。
- 全程只动 `transform` / `opacity`，是纯合成层动画，不重绘页面。
- 渐变层固定 3 倍屏大小再平移，不逐帧重算渐变。
- 连点防重入（`_busy` 锁）；「减弱动效」开启时退化为立即切换，功能完整。

入口：
1. 首页左上角双色圆点 —— 点一下直接在 **暖沙 ↔ 黑金** 之间来回切
2. 我的 → 主题行（自绘开关）—— 同样的来回切
3. 主题持久化在 `storage`，页面栈内所有页面 + tabBar 同时换肤

### 为什么换肤瞬间不做颜色过渡
CSS 变量无法插值（除非 `@property`，小程序不支持），而给几十个节点同时加 `transition: background-color`
会触发大面积重绘。用遮罩遮盖是唯一既好看又不掉帧的做法。

### 黑金的调校（Codex 式）
表面全部走中性深黑（#0D0D0E / #171717 / #212121），发丝线是 9% 灰白而不是金线；
金色 #D4AF37 只出现在强调处（按钮、选中态、强调文字）。**越少越贵**——整屏都是金线反而廉价。

## 六、验证与已知限制

- 已做静态校验：JS `node --check` 全通过、WXML 标签闭合、WXSS 括号配对、无 `transition: all` / 无 `backdrop-filter`。
- **需在开发者工具/真机确认**：
  1. 深色主题下状态栏文字颜色（依赖 `wx.setNavigationBarColor` 的 `frontColor`）；
  2. 长列表换肤时的重绘耗时（理论上被遮罩盖住，但低端机仍可能有一次 100ms 级卡顿）；
  3. 首页为自定义导航，已关闭原生下拉刷新（避免转圈被导航遮挡），改为每次 `onShow` 自动刷新。
- 回滚点：`app.wxss`、`utils/theme.js`、`components/theme-reveal`、`custom-tab-bar`、`pages/{list,detail,my,comments,order-confirm}`。
