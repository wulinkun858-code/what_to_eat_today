## 三、令牌落地

### 3.1 字号：19 → 8

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fs-display` | 72rpx | 首页刊头（原 84） |
| `--fs-h1` | 48rpx | 详情菜名、档案姓名（原 52/44/56） |
| `--fs-h2` | 36rpx | 区块标题、书眉标题（原 32/34/38/40） |
| `--fs-title` | 30rpx | 卡片标题 |
| `--fs-body` | 28rpx | 正文 |
| `--fs-meta` | 24rpx | 次级信息（原 26） |
| `--fs-caption` | 22rpx | 时间戳、辅助说明（下限） |
| `--fs-badge` | 20rpx | **仅**计数徽标 / 印章小字 |

> 20rpx 是唯一低于 22rpx 的档位，且限定在徽标与印章内（英文 10px 量级），不承载正文。

### 3.2 圆角：11 → 4

`12`（小控件）/ `20`（卡片、输入、书眉）/ `28`（面板、大卡、Dock）/ `999`（胶囊）。
原 4/6/8/10/16/18/24 六档全部归并——它们的视觉差不足 2px，只制造“随手写”的观感。

### 3.3 动效：21 档时长 → 7；5 条曲线 → 3

| 令牌 | 值 | 语义 |
|---|---|---|
| `--d-micro` | 120ms | 按压、颜色微变 |
| `--d-short` | 200ms | 按钮、标签切换 |
| `--d-medium` | 280ms | 位移、让位、展开 |
| `--d-long` | 420ms | 区域变化、轮播、页面淡入 |
| `--d-sweep` | 560ms | 主题扫过（唯一超过 500ms 的场景） |
| `--d-loop` / `--d-breathe` | 900 / 1600ms | 循环动画（旋转、骨架呼吸） |

```
--e-standard    cubic-bezier(.2, 0, 0, 1)      /* 位移、展开 */
--e-decelerate  cubic-bezier(.05, .7, .1, 1)   /* 入场，快进长尾 */
--e-spring      cubic-bezier(.2, 1.12, .4, 1)  /* 过冲约 6%，仅小元素 */
```

### 3.4 颜色：保留色相，补齐明度阶梯

| paper `--ink-3` | `#7C7060` | `#6B5F4F` | 3.90 → **5.02** |
| paper `--accent` | `#B4381F` | `#A93218` | 4.80 → **5.36** |

## 四、结构与交互改造

### 4.1 底部 Dock（解决三层叠压）

```
v3:  tab 栏 104rpx（bottom 16） + 点菜单条 96rpx（bottom 140） + FAB 104rpx（bottom 170/276）
     → 三层 fixed 互相遮挡，FAB 的 z-index 90 被点菜单 95 压住

v4:  单层 Dock 112rpx = 书签导航（3 tab）+ 常驻点菜单入口（216rpx）
     → 释放约 150rpx 垂直空间，z 序只剩一层
```

- 购物车数量走 `cart.subscribe`，页面不再向 tabBar `setData` 传值。
- 空点菜单显示“0 点菜单”且不响应点击，避免落到一个只能返回的空页面。
- “想吃”粒子落点同步更新为 Dock 右侧入口中心。

### 4.2 首页首屏

| 项 | v3 | v4 |
|---|---|---|
| 刊头 | 84rpx 两行（今天 / 吃什么） | 72rpx 单行（今天吃什么） |
| 轮播 | 360rpx | 300rpx |
| 品类条 | 104rpx 高 + 88rpx 胶囊 | 104rpx 高 + 72rpx 胶囊 |
| 写菜牌 | 悬浮 FAB | 刊头右侧 88×88rpx 描边印章 |
| 首屏可见 | ≈1.5 行菜品 | **≈2.5 行** |

### 4.3 动效编排

| 场景 | v3 | v4 | 变更理由 |
|---|---|---|---|
| 卡片入场 | 460ms，8×50ms 错峰 | 320ms，5×40ms | 首屏 520ms 内完成 |
| 卡片按压 | 与入场争用 `transform` | 入场挂 `.dish-cell`，按压挂 `.dish-card` | 入场期间按压不再失效 |
| 品类切换 | 过渡 `padding` 300ms | 伪元素 `scaleX` 180ms | 消除布局重排 |
| 轮播 | 520ms / 4200ms | 420ms / 5000ms | 与图片切换同步，降低“赶”感 |
| 主题扫过 | 1270ms，遮罩 `pointer-events:none` | **600ms**，遮罩吞事件 | 交互锁定期减半，杜绝误触 |
| Dock 书签 | 440ms | 280ms | 位移仅 1/3 屏宽 |
| 弹跳过冲 | 约 16% | 6% | 与“≤8%”的自我约束一致 |

### 4.4 详情页

- 头图延伸到状态栏下，透明导航压图，返回键带 34% 墨底保证浅色照片可读。
- 竖排 `.vlabel`（24rpx，逐字断行）改为横排分区标题（22rpx + 4rpx 字距 + 发丝线），承载“简介 / 食材 / 做法 / 留言”。
- 头图圆点从右上移到右下，避让导航与菜牌。
- 底部操作条保留，内容留白统一 `--page-room`。

### 4.5 档案页

- “日|月”“开|关”双段按钮改为**开关**（轨道 96rpx、滑块 40rpx、行程 44rpx），状态不再依赖左右位置推断。
- 补书眉页头，与「留言」tab 同构；tab 页不再依赖原生导航栏。

## 六、验收与未验证项

### 已在本地完成

- 全量静态校验 0 错误。
- 四屏渲染：纸色首页、墨夜首页、详情页、档案页。
- 令牌覆盖率：页面 WXSS 中裸值清零。

### 未验证（必须进开发者工具确认）

1. **自定义导航的安全区**：`nav-bar` 用 `getMenuButtonBoundingClientRect` 推算，需在刘海屏/灵动岛机型核对标题是否与胶囊垂直居中。
2. **下拉刷新 × 自定义导航**：`enablePullDownRefresh` 的 6 个页面改为自定义导航后，刷新指示器可能落在返回条下方，需要逐页确认。
3. **CSS 变量在 `animation` 简写中的兼容性**：`animation: enter var(--d-long) var(--e-decelerate)` 在低版本基础库的表现需实测；若不支持，降级方案是拆成 `animation-name/duration/timing-function` 三条长写。
4. **Dock 订阅时序**：tabBar 实例在页面切换时重建，需确认从「点菜单」返回首页后数量仍然正确。
5. **墨夜主题下的原生窗口底色**：`theme.sync` 仍调用 `setNavigationBarColor`，自定义导航页面该调用无副作用，但需确认不报错。

### 明确的设计取舍

| 取舍 | 说明 |
|---|---|
| 品类签条 72rpx（36px） | 44px 会让横向签条变成一排厚重的按钮，压过标题；36px 满足 WCAG 2.2 AA（24px），且左右留 12rpx 间距降低误触。主操作（想吃 / Dock / 返回 / 底部按钮）仍为 44px。 |
| 搜索清除 64rpx（32px） | 位于 76rpx 高的搜索行内，放大到 44px 会撑破行高；32px 是内联清除按钮的常见尺寸。 |
| 主题扫过 600ms | 比 v3 的 1.26s 短，仪式感靠“墨色铺开 + 一线朱砂”保留；如需更长，改 `--d-sweep` 一处即可。 |
| 保留 5 条 `@keyframes` | `enter` / `fade-in` / `pop-in` / `bar-up` / `stamp-in` 是语义化基元，不再在页面内新增关键帧。 |
